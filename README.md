# FTL Workout

Web app FTL Gym untuk calendar workout, checklist, bobot latihan, profile, dashboard, streak, dan print/PDF.

## GitHub Pages
Settings → Pages → Deploy from branch → main → / (root).

## Catatan cloud history
Versi awal di repository ini berjalan sebagai frontend statis. History saat ini tersimpan di browser. Tahap berikutnya adalah menghubungkan frontend GitHub Pages ke backend Google untuk menyimpan history berdasarkan akun Google.
